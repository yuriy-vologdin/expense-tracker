Expense Tracker CLI
Простой консольный менеджер расходов на Go. Позволяет записывать траты, просматривать список и считать общую сумму. Все данные сохраняются в локальный JSON-файл.

### Функционал
* **Добавление**: `add "описание" сумма`
* **Просмотр**: `list` (выводит таблицу со всеми записями)
* **Статистика**: `summary` (показывает общую сумму всех трат)
* **Удаление**: `delete id` (удаляет конкретную запись по номеру)
